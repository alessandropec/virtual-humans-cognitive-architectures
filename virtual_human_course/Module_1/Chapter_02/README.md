# LLMs, Working Memory and Prompting

Explore how an LLM uses its context and how an agent manages that context.

## Chapter materials

- [Student PowerPoint](Slides/Module_1_Chapter_02_LLMs_Working_Memory_and_Prompting.pptx)
- [Slide PDF](Slides/Module_1_Chapter_02_LLMs_Working_Memory_and_Prompting.pdf)

The chapter introduces Transformers, GPT and scaling laws, then uses prompt examples to explain in-context learning, supplied facts, conversation history and retrieved memories. It closes with working memory as an active workspace managed by code.

Read the [Financial Times interactive](https://ig.ft.com/generative-ai/) when indicated in the slides. For the classroom quiz, open [kahoot.it](https://kahoot.it/) and enter the PIN shown by the instructor.

Prompt completions are teaching illustrations. [Chapter 03](../Chapter_03/README.md) turns these ideas into executable LangChain examples.

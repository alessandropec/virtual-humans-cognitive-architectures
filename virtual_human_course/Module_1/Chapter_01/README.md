# Psychological Foundations of Cognitive Architectures

Connect psychological models of memory to the components of a virtual agent.

## Topics

- Virtual agents and virtual humans
- Cognition and the Perceive-Reason-Act loop
- Psychological models of sensory, short-term, working and long-term memory
- Semantic, episodic, procedural, autobiographical and spatial memory
- ADAMO, Generative Agents and Voyager as concrete examples
- Coscientist and automated chemistry
- Social simulation, game-playing agents, real-world robotics and healthcare training in VR

## Chapter materials

The chapter contains 32 slides. The examples follow the psychological models and identify functional analogies between human memory and agent components. The Multi-Store overview separates memory stores from control processes, which the following slides explain in detail. Memory-model slides use consistent definition and control-process cards. The LTM sequence uses example cards and alternates text and visuals; autobiographical memory connects episodic experiences with personal knowledge and identity. Instructor notes include teaching explanations and sources.
